# `/public`

Static assets served directly by Next.js at the site root (e.g.
`public/globe.svg` → `/globe.svg`).

## Files

| File | Used for |
|---|---|
| `file.svg` | Generic file icon (default Next.js starter asset). |
| `globe.svg` | Generic globe icon (default Next.js starter asset). |
| `window.svg` | Generic window icon (default Next.js starter asset). |

`app/favicon.ico` (not here — Next.js serves any `favicon.ico` placed
directly in `/app`) is the app's actual favicon.

Nothing in this folder is SentinelX-specific yet; add product screenshots,
a logo, or an og-image here if you want richer branding on the deployed
site or in the GitHub README.
